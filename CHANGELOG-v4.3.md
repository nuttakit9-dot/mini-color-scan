# Miniature Paint Scanner v4.3

## UI modernization
- Updated the app to a contemporary miniature-paint studio aesthetic.
- Refreshed light/dark palette, typography scale, header treatment, card surfaces, buttons, and form focus states.
- Reworked the navigation visually into a sticky, horizontally scrollable tab bar to better fit all seven app sections.
- Improved desktop width and small-screen spacing.
- Preserved existing section IDs, JavaScript logic, paint records, and offline/PWA structure.
- Updated service worker cache version to `miniature-paint-scanner-v4-3`.

## Validation
- This build is a visual refresh, not a paint database refresh.
- Full browser/device QA is still recommended.
