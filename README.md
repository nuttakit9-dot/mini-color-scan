# สแกนสีโมเดล Miniature — ชุดไฟล์ทดสอบบนมือถือ (ฟรี)

แท็บ "แนะนำสี" (ที่ใช้ Claude) ปิดไว้ก่อนในชุดนี้ แอปที่เหลือทำงานในเครื่องผู้ใช้ทั้งหมด ไม่มีค่าใช้จ่ายต่อการใช้งาน

ไฟล์ในชุด: `index.html` (ตัวแอป), `manifest.webmanifest` + `sw.js` + ไอคอน (ติดตั้งลงหน้าจอโฮม/ใช้ออฟไลน์), `LICENSE-THIRD-PARTY.txt` (ต้องแจกไปพร้อมแอป), `worker.js` (ไม่ใช้ตอนนี้ เก็บไว้เผื่อเปิดแท็บแนะนำสีภายหลัง)

## 1) นำขึ้นเว็บฟรี (เลือกอย่างใดอย่างหนึ่ง)
ต้องมีบัญชีฟรีของบริการนั้น ๆ และได้ HTTPS ให้เอง ซึ่งจำเป็นต่อกล้องและการติดตั้ง
- **Cloudflare Pages:** Workers & Pages > Create > Pages > Upload assets อัปโหลดโฟลเดอร์ที่แตก zip แล้ว
- **Netlify:** app.netlify.com/drop ลากโฟลเดอร์ไปวาง (ล็อกอินเพื่อให้ไซต์อยู่ถาวร)
- **GitHub Pages:** สร้าง repository อัปโหลดไฟล์ไว้ที่ราก เปิด Settings > Pages

ส่งลิงก์ให้ผู้ทดสอบได้เลย ไม่ต้องมีบัญชีใด ๆ

## 2) ติดตั้งเป็นไอคอนบนมือถือ
- iPhone/iPad: Safari > Share > Add to Home Screen
- Android: Chrome > เมนูสามจุด > Install app หรือ Add to Home screen

## 3) เก็บสถิติการใช้งานแบบไม่ระบุตัวตน (ฟรี)
ใช้ GoatCounter (goatcounter.com) ซึ่งไม่ใช้คุกกี้ ไม่เก็บรูป และไม่ระบุตัวตนผู้ใช้ ฟรีสำหรับงานที่ไม่ใช่เชิงพาณิชย์ ตรวจเงื่อนไขล่าสุดของเขาก่อนใช้
1. สมัคร GoatCounter แล้วเลือกรหัสไซต์ (เช่น `myminiapp`)
2. เปิด `index.html` แก้บรรทัด `const GC_CODE="";` เป็น `const GC_CODE="myminiapp";` แล้วอัปโหลดใหม่
3. เปิดแดชบอร์ดของ GoatCounter ดูจำนวนผู้เข้า และรายการ Events

เหตุการณ์ที่บันทึก: เปิดแอป, สลับแท็บ (`tab_t1`, `tab_t3`), อ่านสีจากรูป (`photo_read`), แตะคัดลอกสี (`copy_hex`), เปิดรายการสีขวดที่ใกล้เคียง (`match_open`), เปิด/ปิดยี่ห้อ (`brand_on_*`, `brand_off_*`), เพิ่มสีเอง (`custom_add`, `custom_import`), ติดตั้งแอป (`installed`)
เมื่อตั้งรหัสไว้ แอปจะแสดงหัวข้อ "ความเป็นส่วนตัว" ในแท็บคลังสี พร้อมช่องให้ผู้ใช้ปิดการเก็บสถิติของตัวเอง

## 4) ก่อนเปิดให้คนทั่วไป
- ข้อมูลไทยโทนมาจาก poakpong.com ซึ่งยังไม่ได้ตรวจเงื่อนไขการนำไปใช้ซ้ำ ถ้าไม่แน่ใจให้ขออนุญาต หรือลบรายการ `[7,"…` ออกจากอาร์เรย์ `DB` ใน index.html
- ข้อมูล Ionic อ่านจากภาพกล่อง เป็นค่าประมาณ
- ถ้าเปิดวงกว้าง ควรตรวจเรื่องกฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA) ของไทยเพิ่มเติม
- แก้ไฟล์แล้วอัปโหลดใหม่ ให้เพิ่มเลข `V` ใน `sw.js` (เช่น mcs-v2) เพื่อให้เครื่องผู้ใช้ดึงเวอร์ชันใหม่
